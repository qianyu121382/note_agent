## 一、项目核心定位
专为Agent 岗位面试打造的实战型 LangGraph 项目，核心解决：多源文件 / 链接自动解析 + 个性化无重复笔记生成 + AI 配图一体化需求，完整体现 LLM Agent、工作流编排、工具调用、本地文件交互等核心能力。

## 二、核心需求
*   **输入源**:
    *   **构思**: 支持用户上传网页链接、视频、文档等多种形式，支持多个文件 / 链接同时输入。
    *   **当前实现状态**: ✅ 已实现**网页链接**、**大段文本**和**本地文件路径**作为输入源。可在一个输入中处理多个来源。
*   **核心处理**:
    *   **构思**: LLM 对多源内容进行解析、整理、归纳。
    *   **当前实现状态**: ✅ 已实现基于**多视角反思（Multi-Perspective Reflection）**的笔记生成机制。该机制通过“草稿 -> 多 Agent 并行评审 -> 修改 -> 再评审”的循环，极大提升了生成笔记的质量、事实性和结构性。
*   **关键能力**:
    *   **构思**: 自动读取用户本地笔记，识别已学习内容，不重复生成笔记。
    *   **当前实现状态**: ✅ **已实现**。通过`Chroma`向量数据库对新内容的嵌入与历史笔记进行相似度比对，有效防止重复记录。
*   **输出要求**:
    *   **构思**: 生成Markdown 格式笔记。
    *   **当前实现状态**: ✅ 已实现高质量的 Markdown 格式笔记输出。

*   **扩展能力**:

## 三、项目技术栈核心（面试导向，仅列核心）
*   **工作流编排**: LangGraph（核心框架，体现 Agent 状态管理、流程控制、子图嵌套）
*   **向量与存储**: ChromaDB（用于内容去重和知识记忆）
*   **大模型能力**: LLM（内容解析 / 格式控制 / 决策 / 多Agent辩论） + 文生图模型（AI 配图）
*   **基础能力**: 多源文件解析、本地文件读写、Markdown 格式化输出

## 四、核心工作流（基于当前实现）
1.  **输入与意图分析 (Input & Dispatch)**: **[✅ 已实现]**
    *   流程的统一入口，基于 LLM 分析用户输入。
    *   准确识别用户意图：是进行笔记 (`note_taking`)、闲聊 (`waiting`) 还是退出 (`exit`)。
    *   从输入中提取出 URL、大段文本或本地文件路径。

2.  **内容提取 (Content Ingestion)**: **[✅ 已实现]**
    *   基于 LangGraph 重构的 ReAct 风格 Agent。
    *   Agent 根据调度员提取的数据类型（url, text, file_path），自主选择并调用相应工具（网页抓取、本地文件读取）。
    *   将所有来源的内容提取并整合为统一的原始文本流。

3.  **内容去重 (Content Deduplication)**: **[✅ 已实现]**
    *   将提取的原始内容通过 Embedding 模型计算向量。
    *   在 `Chroma` 向量数据库中进行相似度搜索。
    *   如果相似度高于阈值，则标记为“重复内容”，并将已有内容注入上下文，供下一步参考。

4.  **多视角反思生成 (Reflective Note Generation)**: **[✅ 已实现]**
    *   **起草 (Draft)**：一个专门的“作家” Agent 根据原始内容和去重结果（如有）生成笔记初稿。
    *   **并行评审 (Parallel Review)**：三位“专家” Agent 从不同角度同时对草稿进行评审：
        *   `事实核查员`: 检查笔记与原文的一致性。
        *   `结构与格式评审员`: 检查 Markdown 格式和逻辑结构。
        *   `新颖性与简洁度评审员`: 检查是否有多余内容，以及是否恰当处理了与历史笔记重复的部分。
    *   **修订 (Revise)**：一位“优化师” Agent 汇总所有评审意见，对笔记进行修改。
    *   流程会循环（评审 -> 修订），直到所有评审员都满意或达到最大修订次数，确保最终输出高质量的笔记。
