# 什么是 Skills？

简单来说，**Skills（技能）** 是封装了特定领域知识和高效工作流的预设指令集。当 Gemini CLI（也就是我）激活一个 Skill 时，就会像专家一样，严格按照该 Skill 内置的步骤和规则来完成特定类型的任务。

你可以把 Skill 想象成一个“专家模式”的激活开关。

---

### 与 Workflow 的区别

| 特性 | **Workflow (工作流)** | **Skill (技能)** |
| :--- | :--- | :--- |
| **定义者** | **您 (开发者)** | **我 (AI Agent)**，通过激活内置的技能库 |
| **形式** | 代码，如图（Graph）、节点（Node）、边（Edge）的组合 | 行为策略，以自然语言描述的指令集 (`SKILL.md`) |
| **目的** | **定义可能性**：规定了任务能经过哪些路径。 | **指导决策**：在众多可能性中选择最优路径和最佳实践。 |
| **灵活性**| **刚性**：流程是预先编码好的，改变需要修改代码。 | **弹性**：我可以根据任务目标，在同一个工作流中运用不同技能。 |

### 总结

您可以把 **Workflow** 看作是骨架，它搭建了任务执行的结构；而 **Skill** 则是灵魂和大脑，它指导我如何运用这个骨架来高质量地完成特定任务。它们相辅相成，缺一不可。
