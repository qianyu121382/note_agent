# Codex CLI 使用指南

在 Codex CLI 中，可以使用 `codex resume` 命令继续上一次对话。以下是详细的使用方法和常见问题解答。

## 一、快速继续最近一次对话（最常用）

自动恢复最近一次会话：
```bash
codex resume --last
```
或直接指定任务：
```bash
codex resume --last "继续刚才的任务"
```

## 二、手动选择历史会话

列出所有可恢复会话，手动选择：
```bash
codex resume
```
执行后会显示会话列表，输入序号即可继续。

## 三、按会话 ID 恢复

使用实际会话 ID 进行恢复：
```bash
codex resume 123e4567-e89b-12d3-a456-426614174000
```

## 四、非交互模式继续（脚本 / 自动化）

在非交互模式下恢复最近会话并执行新指令：
```bash
codex exec resume --last "继续补全测试"
```

## 常见问题

- **找不到历史会话**：确保在同一台机器、同一用户下运行，会话默认保存在 `~/.codex/sessions`。
- **恢复后上下文不全**：建议先让 AI 总结当前会话状态，再继续任务。
