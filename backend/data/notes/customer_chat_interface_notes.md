# 代理开发笔记

## 1. 客服聊天界面概述

客服聊天界面是一个 **Next.js** 应用程序，旨在提供与 **LangChain** 代理的对话接口。其主要特点包括：

- **实时聊天**：支持即时交互。
- **工具可视化**：可视化展示工具的使用。
- **时间旅行调试**：允许用户回溯和调试对话状态。
- **状态分叉**：支持多种对话状态的管理。

该界面与使用 **create_agent** 技术创建的客服系统无缝协作，适用于本地运行或部署环境（如 **LangSmith**）。此外，座席聊天UI是开源的，用户可以根据需求进行调整。

## 2. 快速入门

要快速开始使用客服聊天界面，请按照以下步骤操作：

1. 访问客服聊天界面。
2. 输入部署URL或本地服务器地址以连接代理。
3. 开始聊天，界面会自动检测并渲染工具调用和中断。

## 3. 本地开发

若需自定义或进行本地开发，可以按照以下步骤运行 **Agent Chat UI**：

### 3.1 使用 NPX

1. 克隆仓库：
   ```bash
   # 创建新的 Agent Chat UI 项目
   npx create-agent-chat-app --project-name my-chat-ui
   cd my-chat-ui
   ```
2. 安装依赖并启动：
   ```bash
   pnpm install
   pnpm dev
   ```

## 4. 连接代理

客服聊天界面支持同时连接两个本地及部署代理。启动界面后，需配置以下信息以连接座席：

- **图ID**：输入图名（可在 `graphslanggraph.json` 文件中找到）。
- **部署URL**：代理服务器的端点（例如本地开发使用 `http://localhost:2024`）。
- **LangSmith API 密钥（可选）**：添加 LangSmith API 密钥（如果使用本地代理服务器则非必需）。

配置完成后，代理聊天界面会自动获取并显示代理中断的线程。客服聊天界面开箱即用，支持工具调用和工具结果消息的呈现。有关自定义显示消息的更多信息，请参见相关文档以隐藏聊天中的消息.
