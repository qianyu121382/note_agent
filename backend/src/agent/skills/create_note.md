# create_note

适用场景：
- 用户提供新的原始资料，希望整理成笔记
- 输入可能是 URL、长文本、文件路径，或其组合

任务目标：
- 从原始资料中提取核心信息
- 必要时翻译或清洗内容
- 生成结构化、高质量的 Markdown 笔记
- 在需要保存时创建新的笔记记录

工作步骤：
1. 判断资料是否已经足够；如果内容缺失或过于模糊，先澄清。
2. 如果用户提供的是本地文件路径，优先用 `read_local_document` 读取。
3. 如果内容包含大量英文且用户需要中文笔记，可使用 `translate_english_to_chinese`。
4. 使用 `refine_and_generate_note` 生成最终 Markdown 笔记。
5. 如果用户明确要保存，或当前任务明显是在“正式创建笔记”，使用 `create_note_record` 保存。
6. 回复时明确说明创建结果，并提供 `note_id`。

执行约束：
- 不要凭空捏造资料中不存在的信息。
- 输出正文应是完整 Markdown，而不是零散摘要。
- 创建新笔记时，优先通过 `create_note_record` 保存，而不是手动管理文件名。
